+ Officer Settings

Create a webhook in Discord for each notification you want: Server Settings → Integrations → Webhooks → New Webhook, pick the channel, copy each URL into its field above. For the role ping: enable Developer Mode (User Settings → Advanced), then right-click your Officer role in Server Settings → Roles → Copy Role ID. Leave any field blank to skip that notification. Note: these URLs are visible to anyone who views the page source, so use low-stakes channels.
