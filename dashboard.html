+ Officer Settings

Create a webhook in Discord: Server Settings → Integrations → Webhooks → New Webhook, pick your officer channel, copy the URL. For the role ping: enable Developer Mode (User Settings → Advanced), then right-click your Officer role in Server Settings → Roles → Copy Role ID. Leave the role field blank for no ping. Note: the webhook URL is visible to anyone who views the page source, so use a low-stakes officer-only channel.
