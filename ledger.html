Sync a Log

Pulls attendance, gear, enchants, gems, and consumable usage from a Warcraft Logs report. Your WCL credentials stay in this browser only. Loot still goes through the separate RCLootCouncil import.

This needs a V2 API Client from warcraftlogs.com/api/clients — click "Create Client" there to get a real Client ID + Client Secret pair. This is not the same as the "V1 Client Name / Key" shown under your account's Web API settings — that's a different, older system and won't work here.

Honest limitation: this is stored so officers don't see it in this form, but since everything runs in the browser, a technically determined officer could still find it via browser dev tools (Network tab) while a sync runs. True secrecy needs a server-side proxy, which isn't built yet.

While testing: pulls every player in the report, regardless of guild. Flag it once you're ready to lock this to Delusions only.
